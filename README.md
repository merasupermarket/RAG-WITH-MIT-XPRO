# RAG-WITH-MIT-XPRO

## Overview & System Capabilities

The **Wikipedia Retrieval Engine** acts as an intelligent assistant that helps users easily explore and learn from a large collection of Wikipedia articles covering famous people, historical events, places, and general concepts.

---

## Supported Interactions

The system supports four main types of user interactions:

* **Answering Factual Questions**  
  Users can ask direct questions to get quick, specific facts (e.g., inquiring about a person's birth date, a historical event's location, or a scientific definition).

* **Citation & Multi-Document Retrieval**  
  Supports both single-document and multi-document questions, providing direct quotations and citations from source material.

* **Context-Aware Conversations**  
  Remembers the context of the back-and-forth conversation. If a user asks a follow-up question like *"Where was he born?"* or *"Can you explain that last point in simpler terms?"*, the system understands the referenced entities without requiring full context repetition.

* **Grounded Answers with Direct Quotes**  
  To ensure accuracy and prevent false information (hallucinations), the system backs up its answers by citing source Wikipedia articles and including direct, word-for-word quotations so users can instantly verify the facts.
